# 游戏内抗锯齿与超分辨率系统

## 项目描述

游戏内抗锯齿与超分辨率系统的bug修复项目。核心模块 `rendering/antialiasing.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 抗锯齿完全没做边缘都是锯齿
- 超分辨率完全没做只能做简单的双线性插值
- DLSS完全没做不能用AI超分辨率
- TAA完全没做不能做时间抗锯齿
- FSR完全没做不能做空间超分辨率

## 运行测试

```bash
python -m pytest tests/test_antialiasing.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
